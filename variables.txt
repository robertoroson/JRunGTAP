All variables are expressed as percentage changes (% change) from benchmark.

Select the section for the model version you are using:
  • Section 1 — GTAP v6.2  (model = v62, the default)

───────────────────────────────────────────────────────────────────────────────
SECTION 1 — GTAP v6.2
───────────────────────────────────────────────────────────────────────────────
Index dimensions: T=traded commodities, E=endowments,
P=production sectors (T ∪ CGDS), M=transport margins, R=regions,
NS=non-savings commodities (T ∪ endowments).

In the standard short-run closure all ENDOGENOUS variables are determined by
the model; all EXOGENOUS variables are set by the user (shocks). A closure swap
moves one variable from each list, keeping the system square.

── COMMON CLOSURE SWAPS (v6.2) ───────────────────────────────────────────────
Long-run (mobile capital, fixed rate of return):
  swap  rental[R]  <->  qo_endw[Capital, R]    for each region R

Fixed real wages:
  swap  rental[R]  <->  qo_endw[UnSkLab, R]
  swap  rental[R]  <->  qo_endw[SkLab, R]

Endogenous tariff (fixing import volume):
  swap  tm[T, R]   <->  qxs[T, origin, R]

Endogenous export tax (fixing trade balance):
  swap  tx[T, R]   <->  qxs[T, R, destination]

SECTION 2 — GTAP v7  (Corong et al. 2017)
───────────────────────────────────────────────────────────────────────────────
Key structural differences from v6.2:
  • Activities (A) are separate from commodities (C); linked by make matrix.
  • Three endowment types: Mobile (EM), Sluggish (ES), Fixed (EF).
  • Additional nesting: ESUBT (VA vs. intermediates), ESUBC (among intermediates).
  • Activity-specific taxes: to(C,A,R), tinc(E,A,R), tfe(E,A,R).

Index dimensions: C=commodities, A=activities, E=endowments (all),
EM=mobile endowments, ES=sluggish endowments, EF=fixed endowments,
EMS=mobile+sluggish, EC=capital endowments, M=transport margins, R=regions.

NOTES (both versions)
───────────────────────────────────────────────────────────────────────────────
• Variable names in cfg files are case-insensitive (tm = TM = Tm).
• Index names must match the labels in your GTAPAgg3 aggregation
  (run load_data() / load_data_v7() and inspect the printed set names).
• "all" or "*" may be used as a wildcard index: tm[all, Austria] = 10.0
• Model-set names (TRAD_COMM, REG, ENDW_COMM, ACTS, …) may be used as indices.
• User-defined sets can be declared inline: set agri = [pdr, wht, gro]
• In v7, activities (ACTS) and commodities (COMM) may differ. Check both set
  names in your aggregation before writing shocks.
