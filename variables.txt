JRunGTAP — Variable Reference
═══════════════════════════════════════════════════════════════════════════════
All variables are expressed as percentage changes (% change) from benchmark.
Index dimensions are shown in parentheses: T=traded commodities, E=endowments,
P=production sectors (T ∪ CGDS), M=transport margins, R=regions,
NS=non-savings commodities (T ∪ endowments).

In the standard short-run closure all ENDOGENOUS variables are determined by
the model; all EXOGENOUS variables are set by the user (shocks). A closure swap
moves one variable from each list, keeping the system square.

───────────────────────────────────────────────────────────────────────────────
COMMON CLOSURE SWAPS
───────────────────────────────────────────────────────────────────────────────
The standard short-run closure fixes all factor supplies (qo_endw) and lets
the rental rate (rental) be determined endogenously. The most common swaps:

Long-run (mobile capital, fixed rate of return):
  swap  rental[R]  <->  qo_endw[Capital, R]    for each region R
  (capital stock adjusts to equate the rate of return across regions)

Fixed real wages (labour market targeting):
  swap  rental[R]  <->  qo_endw[UnSkLab, R]
  swap  rental[R]  <->  qo_endw[SkLab, R]

Endogenous tariff (fixing import volume):
  swap  tm[T, R]   <->  qxs[T, origin, R]       for specific (T, origin)

Endogenous export tax (fixing trade balance):
  swap  tx[T, R]   <->  qxs[T, R, destination]

NOTES
───────────────────────────────────────────────────────────────────────────────
• Variable names in cfg files are case-insensitive (tm = TM = Tm).
• Index names must match the labels in your GTAPAgg3 aggregation
  (run load_data() and inspect the printed set names).
• "all" or "*" may be used as a wildcard index: tm[all, Austria] = 10.0
• Model-set names (TRAD_COMM, REG, ENDW_COMM, …) may be used as indices.
• User-defined sets can be declared inline: set agri = [pdr, wht, gro]
